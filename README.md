# All-sky Camera

Continuation of an all-sky camera project at Aalto University

## Specifications
Camera: ZWO ASI676MC

Computer: Raspberry Pi 5

## Set-up and Requirments 
It is recommended to use Python version 3.12.

The easiest way to install would be to clone this repo and execute the following commands:
```
python3.12 -m venv <repo>

cd <repo>
source bin/activate

pip -r requirements.txt
```
